# Rock, Paper, Scissors + Well

A Python console game that extends the classic "Rock, Paper, Scissors" by introducing a fourth option: the **Well**. This project demonstrates clean code structure, input validation, and customized game logic.

## 🎮 Game Rules
The addition of the **Well** creates a new dynamic and requires updated conditional logic:
- 🪨 **Rock** beats Scissors (blunts them).
- ✂️ **Scissors** beat Paper (cut it).
- 📄 **Paper** beats Rock and Well (covers them).
- 🕳️ **Well** beats Rock and Scissors (they sink inside).

## 🛠️ Technical Features
- **Robust Input Validation:** The game handles unexpected user entries gracefully without crashing.
- **Session Scoreboard:** Keeps track of player wins, computer wins, and draws during the game session.
- **Modular Design:** Written with clean, separated functions for menu handling, game loops, and win determination.

## 💻 How to Run
1. Make sure you have Python 3 installed.
2. Download the `rock_paper_scissors.py` file.
3. Open your terminal, navigate to the folder, and run:
   ```bash
   python rock_paper_scissors.py
   ```
